# 🚗 Car Price Prediction

## 📌 Project Overview
This project predicts car prices using machine learning techniques.

## 📊 Dataset
Dataset sourced from Kaggle (used for practice purposes).

## 🔧 Tech Stack
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib / Seaborn

## 📈 Workflow
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Model Training
- Evaluation

## 📊 Results
- Best Model: Random Forest
- R² Score: 0.89

## 🚀 Future Improvements

- Deployment
